Политика конфиденциальности

Как MORPH DESK работает с информацией на Windows и при использовании сетевых функций.

Рабочие материалы хранятся локально

MORPH DESK хранит заметки, вложения, доски, записи, настройки и историю в профиле Windows. Папку для резервных копий вы выбираете сами. Деинсталлятор отдельной EXE-версии сохраняет рабочие данные и скачанные модели. Экспортированные копии остаются в выбранной папке.

Локальный ИИ и голос

ИИ и голосовые инструменты обрабатывают данные локально после установки нужных моделей. Приложение использует микрофон, когда вы запускаете запись или голосовую функцию.

Сетевые сервисы

Погода передаёт выбранное местоположение Национальной метеослужбе США. Интерактивная карта запрашивает данные у OpenFreeMap. Если подключён онлайн-переводчик, отправленный вами текст получает настроенный провайдер. Для загрузки моделей используются GitHub или Hugging Face. Эти сервисы обрабатывают запросы по своим правилам.

Магазин и интеграции

Покупки и сведения о лицензиях Microsoft Store обрабатывает Microsoft. Вы определяете, какие материалы доступны стороннему клиенту через локальный Bridge. Клиент может обрабатывать открытые ему материалы.

Управление данными

Вы можете экспортировать резервную копию и удалить локальные материалы и дополнительные модели. Сохраните нужные данные перед удалением файлов. Для удаления скачанных пакетов воспользуйтесь Model Manager. Данные учётной записи и покупок управляются через Microsoft Store.
