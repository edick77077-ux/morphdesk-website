Support

Answers for setup, workspace data and using optional features.

What do I need to run MORPH DESK?

Use Windows 11 x64. The interactive map requires Microsoft Edge WebView2 Runtime. An internet connection is needed for maps, U.S. weather, Microsoft Store features and initial model downloads.

How do I back up my workspace?

Open the backup tools in MORPH DESK and export a backup to a folder of your choice. Keep a copy outside the workspace folder before reinstalling or changing computers. Use the restore tools to open the backup when needed.

Why are the AI tools unavailable?

AI Broker and English Conversation are part of Hybrid. Install the required models in Model Manager. For voice features, also install the required voice packs and check your microphone and output device in Windows.

How do I restore access to Hybrid?

Sign in to Microsoft Store with the account used for the purchase. When the Store edition is available, use Restore purchases in the Free / Hybrid screen. Keep the Store connection active while verifying the license.
